# Roadmap

## M0 — foundation

- monorepo;
- Go API;
- PostgreSQL/Redis;
- auth;
- PWA shell;
- unit/integration tests;
- CI/CD templates.

## M1 — словарь

- CSV/XLSX import;
- нормализация и дедупликация 800+ слов;
- категории, транскрипции и примеры;
- поиск и фильтры;
- пользовательское состояние слова.

## M2 — интервальные повторения

- SM-2 baseline;
- дневная очередь;
- типы упражнений;
- история ответов и статистика;
- streak и цели.

## M3 — AI coach

- генерация контекстных примеров;
- проверка свободного ответа;
- технические диалоги Data Engineering;
- контроль стоимости и кэш AI-ответов.

## M4 — production hardening

- backup/restore drills;
- rate limiter;
- Prometheus metrics;
- tracing;
- SLO/alerts;
- security review;
- полноценный production deployment.
