# ADR-0001: Monorepo и PWA как первый клиент

- Статус: принято
- Дата: 2026-07-16

## Решение

Использовать monorepo с Go backend и Next.js PWA. Нативный SwiftUI-клиент не входит в MVP.

## Причины

- PWA устанавливается на экран iPhone без App Store и TestFlight;
- обновление интерфейса происходит сразу после web deploy;
- основная учебная ценность проекта остаётся в Go backend;
- один frontend работает на iPhone, Mac и desktop;
- архитектура API сохраняет возможность позже добавить SwiftUI-клиент.

## Последствия

Некоторые iOS API и фоновые сценарии будут ограничены по сравнению с native app. Для первого продукта это приемлемо.
