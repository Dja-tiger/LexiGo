# Указания для агентов и разработчиков LexiGo

Этот файл является точкой входа в единый нормативный набор инструкций проекта. Перед любой write-операцией необходимо последовательно прочитать:

1. [`AGENTS.base.md`](./AGENTS.base.md) — полный базовый регламент production-разработки, pre-flight, тестирования и журнал ранее обнаруженных категорий ошибок;
2. [`AGENTS.progress-pr214.md`](./AGENTS.progress-pr214.md) — обязательные дополнения, подтверждённые при разработке PR #214.

Оба документа обязательны и применяются совместно. При расхождении более конкретное правило из `AGENTS.progress-pr214.md` имеет приоритет для route islands, accessibility locators, reduced motion, direct-detail mocks, Linux visual artifacts и temporary workflow lifecycle.

Полная консолидированная версия этих двух документов формируется как артефакт `LexiGo-AGENTS.md`; модульное хранение в repository исключает потерю базового журнала при добавлении новых production-наблюдений.
